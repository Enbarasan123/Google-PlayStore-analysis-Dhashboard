📱 **Google Play Store Analysis Dashboard | Power BI Project**

Excited to share another Data Analytics project built using **Microsoft Power BI!** 🚀

In this project, I developed an interactive Google Play Store Analysis Dashboard to explore app performance, installations, ratings, pricing models, and category-wise trends.

🔍 **Key Insights & Features:**

- Total Number of Apps
- Free Apps Analysis
- Total App Installations
- Maximum Installations
- Total Ratings
- Category-wise App Analysis
- Free vs Paid App Comparison
- App Ratings Analysis
- Content Rating Distribution
- Year-wise App Release and Installation Trends

🛠️ **Tools & Concepts Used:**
- Microsoft Power BI
- Data Visualization
- Interactive Slicers and Filters
- KPI Cards
- Charts and Graphs
- Business Intelligence

🎯 **Project Objective:**

To analyze Google Play Store application data, understand app performance, identify popular categories, and explore trends in user ratings and installations.

Through this project, I improved my practical skills in data analysis, dashboard development, and transforming raw data into meaningful business insights.

Every project is another step forward in my Data Analytics journey! 📊
